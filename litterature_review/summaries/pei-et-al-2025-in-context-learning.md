# Understanding In-Context Machine Translation for Low-Resource Languages: A Case Study on Manchu

**Authors:** Renhao Pei, Yihong Liu, Peiqin Lin, François Yvon, Hinrich Schütze
**Year:** 2025
**Venue:** Proceedings of the 63rd Annual Meeting of the Association for Computational Linguistics (ACL 2025)

---

## Core Argument

High-quality dictionaries and retrieved parallel sentence examples substantially improve in-context machine translation for extremely low-resource languages, while grammar books contribute little to translation quality. Using an enciphered version of Manchu to control for LLM prior knowledge isolates the true contribution of in-context learning, and demonstrates that ICL-generated synthetic parallel data can bootstrap a more efficient conventional MT model.

## Key Concepts

- **Manchu:** An extremely low-resource, critically endangered Tungusic language; used as the test case because it is effectively unseen by current LLMs, enabling clean ICL experiments.
- **Encipherment control:** Replacing Manchu tokens with invented cipher tokens to eliminate any LLM prior knowledge of the language, isolating the effect of in-context learning from pretraining exposure.
- **In-context machine translation (ICL MT):** Performing translation by providing the LLM with dictionary entries, grammar excerpts, and/or parallel sentence examples directly in the prompt, without any fine-tuning.
- **Parallel data augmentation via ICL:** Using ICL-generated translations to create synthetic parallel data, which is then used to train a smaller, more efficient conventional MT model.
- **Chain-of-thought (CoT) prompting for translation:** Adding reasoning steps to translation prompts; found to introduce errors through iterative reasoning rather than improve output.

## Main Findings

- High-quality dictionaries and good parallel examples significantly improve ICL MT quality; grammar books contribute little and sometimes harm performance.
- The encipherment experiments show that LLM prior knowledge of Manchu (even minimal) inflates apparent ICL performance; removing it reveals the true contribution of each resource type.
- LLMs already encode some morphological knowledge (e.g., plural suffixes) that aids translation without explicit grammar instruction, suggesting general linguistic priors are useful.
- Synthetic parallel data generated by ICL MT can train a conventional MT model that is more efficient and often outperforms the ICL approach alone.
- Chain-of-thought prompting worsens translation by introducing errors at each reasoning step.

## Relevance to Indigenous AI

The Manchu case study is highly analogous to the Mohawk situation: an endangered language effectively unseen by current LLMs, with available dictionary resources but limited parallel corpora. The finding that dictionary quality is the most impactful resource type suggests that investing in high-quality Mohawk dictionaries and morphological glossaries would be the highest-priority data effort. The ICL-to-MT bootstrapping pathway (generate synthetic parallel data via ICL, then train a conventional model) is a concrete and actionable pipeline for Mohawk given the absence of existing parallel corpora. The encipherment methodology is also a useful tool for evaluating whether any apparent model knowledge of Mohawk is genuine or residual pretraining noise.

## Limitations & Critiques

- Manchu, while XLR, is an agglutinative language; it does not fully capture the polysynthetic complexity of Mohawk, where morphological composition is more extreme.
- The paper evaluates ICL MT primarily on translation quality metrics (BLEU, chrF, SBERT); cultural fidelity and community-appropriate language use are not assessed.
- Community members or Manchu speakers are not involved in the evaluation; quality judgments are fully automated.

## Questions & Follow-ups

- Would the ICL bootstrapping pipeline (dictionary + examples → synthetic parallel data → fine-tuned model) work for Mohawk given the polysynthetic verb morphology, which makes sentence alignment more complex?
- What is the minimum dictionary quality threshold needed for ICL MT to produce usable synthetic parallel data for Mohawk?
- Related work: Aycock et al. (2025), Tanzer et al. (2024), Zebaze et al. (2025) (example retrieval strategies for ICL MT).
