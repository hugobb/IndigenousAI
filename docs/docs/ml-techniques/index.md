# ML Techniques

A curated inventory of machine learning and NLP techniques applicable to low-resource and indigenous language AI development. Each technique includes a detailed description, implementation guidance, empirical evidence, and known limitations.

## Techniques

| Technique | Short Description | Applicable Data Regime | Link |
| --- | --- | --- | --- |
| Tokenizer–Model Co-Design | Design tokenizer in conjunction with model architecture and training objectives rather than inheriting an existing one; critical for polysynthetic and morphologically rich languages | any | [./tokenizer-model-co-design](./tokenizer-model-co-design.md) |
| Tokenizer Multi-Dimensional Evaluation | Evaluate tokenizer quality across five dimensions (coverage, generalizability, linguistic alignment, robustness, representation utilization) rather than relying on fertility or compression alone | any | [./tokenizer-multidimensional-evaluation](./tokenizer-multidimensional-evaluation.md) |
| MorphScore Tokenizer Evaluation | Measure the proportion of token boundaries that align with morpheme boundaries to audit tokenizer morphological alignment; note that higher scores do not predict better LM performance | any | [./morphscore-tokenizer-evaluation](./morphscore-tokenizer-evaluation.md) |
| Byte-Premium Data Scaling | Correct for encoding-size disparities between languages when setting training data budgets by scaling data quantities according to each language's byte cost relative to English | any | [./byte-premium-data-scaling](./byte-premium-data-scaling.md) |
| Grammar Book Parallel Data Extraction | Systematically extract parallel sentence examples, IGT triples, and word lists from grammar books to build a task-aligned parallel corpus for MT fine-tuning or in-context prompting | zero-resource / &lt;1K sentences | [./grammar-book-parallel-extraction](./grammar-book-parallel-extraction.md) |
| Typological Feature Prompting | Encode a language's high-level grammatical properties (word order, morphological type, evidentiality, etc.) from Grambank into a structured LLM prompt; improves linguistic tasks (grammaticality, IGT) but not MT | zero-resource / &lt;1K sentences | [./typological-feature-prompting](./typological-feature-prompting.md) |
| FST Morphological Segmentation for Polysynthetic MT | Pre-segment polysynthetic words into morpheme sequences using a finite-state transducer before NMT training; reduces 82–87% OOV rates in Algonquian languages to manageable vocabulary sizes | &lt;1K sentences / 1K–10K sentences | [./fst-morphological-segmentation](./fst-morphological-segmentation.md) |
| Cross-Lingual ICL with Query Alignment | Use high-resource-language demonstrations in LLM prompts for low-resource language tasks; apply query alignment (not label alignment) and SBERT-based semantic retrieval to select relevant examples | zero-resource / &lt;1K sentences | [./cross-lingual-icl-query-alignment](./cross-lingual-icl-query-alignment.md) |
| LLM-RBMT Hybrid Translation | Combine rule-based grammar tools with LLM orchestration for grammatically guaranteed translation in zero-resource settings; decomposes source sentences into structured clauses, applies deterministic grammar functions, then validates via back-translation | zero-resource (no parallel corpus) | [./llm-rbmt-hybrid-translation](./llm-rbmt-hybrid-translation.md) |
| Back-Translation Semantic Evaluation | Evaluate translation quality without reference translations by back-translating system output and computing semantic similarity to the original; use baseline null-distribution contextualization to make scores interpretable | zero-resource (no reference translations) | [./back-translation-semantic-evaluation](./back-translation-semantic-evaluation.md) |
| Compression Ratio as Tokenizer Selection Criterion | Use bytes-per-token compression ratio as a cheap, model-free, monotonically reliable predictor of downstream task performance; rank tokenizer candidates before any model training | any | [./compression-ratio-tokenizer-selection](./compression-ratio-tokenizer-selection.md) |
| Textbook Prompting (TALENT) for Low-Resource MT | Improve LLM translation for low-resource languages by constructing a structured textbook (vocabulary list + language examples), guiding the LLM through explicit syntax pattern absorption, then translating; no parallel corpus required | zero-resource / &lt;1K sentences | [./textbook-prompting-talent](./textbook-prompting-talent.md) |
| Back-Translation Data Augmentation | Generate synthetic parallel training data by translating monolingual target-language text with a reverse model; the dominant data augmentation strategy for low-resource MT when monolingual data is more abundant than parallel data | &lt;1K–10K sentences (requires minimal parallel seed) | [./back-translation-data-augmentation](./back-translation-data-augmentation.md) |
| Neural Seq2Seq Morphological Segmentation for Polysynthetic Languages | Character-level encoder-decoder model with multi-task regularization (autoencoding) and cross-lingual transfer for morphological surface segmentation of polysynthetic languages with fewer than 1,000 labeled examples | &lt;1K labeled examples | [./neural-morphological-segmentation-polysynthetic](./neural-morphological-segmentation-polysynthetic.md) |
| WordWeaver FST Verb Conjugator Framework | Open-source framework for building community-facing verb conjugators for polysynthetic languages; separates an FST linguistic back-end (foma/lexc) from a progressive web application front-end; demonstrated on Kanyen'kéha (Mohawk) with 100,000+ conjugated forms | any (rule-based; requires FST grammar) | [./wordweaver-fst-conjugator](./wordweaver-fst-conjugator.md) |
| Decentralized Predictive Text for Indigenous Languages | Generate smartphone keyboard word-completion models from a community-maintained word list spreadsheet, without sending any language data to a central server; integrates with the open-source Keyman keyboard platform | any (word-list sufficient; no parallel data required) | [./decentralized-predictive-text](./decentralized-predictive-text.md) |
| Read-Along Audio Alignment (Zero-Shot Forced Alignment) | Automatically synchronize a written text with its audio recording at word level using cross-lingual phoneme mapping and a donor-language acoustic model; transforms archived Elder recordings into interactive read-along materials with zero target-language training data | zero-resource | [./read-along-audio-alignment](./read-along-audio-alignment.md) |
| Chain-of-Dictionary (CoD) Prompting for Low-Resource MT | Augment an LLM translation prompt with a chained multilingual dictionary — expressing each source word's meaning across multiple high-resource intermediate languages — to elicit translation for low-resource languages without any parallel corpus; achieves up to 13× chrF++ improvements and outperforms both zero-shot and few-shot ICL baselines | zero-resource / &lt;1K sentences | [./chain-of-dictionary-prompting](./chain-of-dictionary-prompting.md) |
| Unsupervised Morphological Segmentation for Polysynthetic MT | Use unsupervised morphological segmenters (Morfessor/FlatCat/LMVR) instead of BPE as the preprocessing step for NMT when the language is polysynthetic and the corpus is extremely small; outperforms BPE on 5 of 8 language directions; supervised segmentation paradoxically underperforms despite higher F1 scores | &lt;1K sentences / 1K–10K sentences | [./unsupervised-morphological-segmentation-for-polysynthetic-mt](./unsupervised-morphological-segmentation-for-polysynthetic-mt.md) |
| ICL-MT Bootstrapping: Dictionary + Examples → Synthetic Parallel Data → NMT | Two-stage pipeline for zero-resource MT: use an LLM with dictionary + BM25-retrieved parallel examples in-context to translate a monolingual corpus into synthetic parallel data, then fine-tune a small NMT model (mT5-small) on the result; the fine-tuned 300M-parameter model matches Llama3-70B performance at ~1/233 the inference cost | zero-resource / &lt;1K sentences | [./icl-mt-bootstrapping](./icl-mt-bootstrapping.md) |
| Tiny-Data LLM Fine-Tuning for Endangered Languages | Fine-tune a pretrained multilingual MT model (NLLB-200, mBART50) on 3K–7K carefully curated Indigenous language sentences to produce functional translators and writing-support tools; bilingual over multilingual, curated quality over raw quantity, human usefulness evaluation over automatic metrics only | &lt;1K–10K sentences | [./tiny-data-llm-fine-tuning](./tiny-data-llm-fine-tuning.md) |
