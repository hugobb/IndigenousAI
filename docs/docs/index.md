# Indigenous AI — Technique Guide

A practical guide for building AI tools for indigenous language revitalization.
Developed at **Mila** (Montréal Institute of Learning Algorithms) in partnership with the Six Nations community.

---

## How to use this site

Each technique doc answers:

- **What is it?** — Detailed description implementable without reading the original paper
- **When to use it?** — Data regime, language typology, compute constraints
- **How to apply it?** — Step-by-step instructions and pseudocode
- **Does it work?** — Empirical evidence with numbers, convergence/conflict across papers
- **What are the limits?** — Documented failure modes and weaknesses

A **Self-Review Notes** block at the end of each doc flags any gaps identified during quality review.
