# Process & Methodology Techniques

A curated inventory of process, governance, and methodology techniques for ethically and effectively developing AI with indigenous communities. Each entry includes practical guidance, evidence from the literature, and known considerations.

## Techniques

| Technique | Short Description | Applicable Context | Link |
| --- | --- | --- | --- |
| Tokenizer Reuse Audit | Structured process to evaluate whether an inherited tokenizer is fit for a new language or domain before deployment; produces an evidence-based reuse/adapt/replace decision | Before deploying any pretrained model on an underrepresented or low-resource language | [./tokenizer-reuse-audit](./tokenizer-reuse-audit.md) |
| Data Volume as Primary Lever | Investment principle: data quantity (byte-premium-scaled) is the dominant lever for closing the performance gap in morphologically complex languages, not architectural complexity | Any low-resource language project; especially when tempted to invest in architecture before data | [./data-volume-as-primary-lever](./data-volume-as-primary-lever.md) |
| Task-Appropriate Data Selection | Match data collection type (parallel sentences, IGT, typological features, grammatical descriptions) to the target NLP task; parallel data drives MT gains while typological/grammatical data drives linguistic task gains | Any XLR/low-resource project deciding how to allocate scarce data collection effort | [./task-appropriate-data-selection](./task-appropriate-data-selection.md) |
| Community-Driven Goal Identification | Discover and center community priorities — knowledge transmission, identity, wellbeing — before scoping any language technology; prevents building systems that serve researcher agendas rather than community needs | Before scoping any language technology project involving an Indigenous or minority language community | [./community-driven-goal-identification](./community-driven-goal-identification.md) |
| Yarning as Research Engagement | Sustained, reciprocal, story-based engagement method that builds genuine relationships before any technical agenda; prevents extractive consultation and surfaces what communities actually want from technology | At the start of any project where no prior relationship exists with the community | [./yarning-as-research-engagement](./yarning-as-research-engagement.md) |
| Realist Evaluation Framework | Evaluate technology by asking "what mechanisms produced what outcomes in what contexts?" rather than system performance alone; includes accountability metrics for Indigenous budget share, sustainability, voice, and capability expansion | When evaluating the impact of any language technology deployed with or for an Indigenous community | [./realist-evaluation-framework](./realist-evaluation-framework.md) |
| Responsive and Responsible ILT Design | Two-axis design standard: responsive (addresses community-identified needs) and responsible (respects Indigenous governance, data protocols, and cultural sovereignty); frames technology as an anticolonial act when both conditions are met | When scoping, designing, or evaluating any Indigenous language technology tool | [./responsive-responsible-ilt-design](./responsive-responsible-ilt-design.md) |
| Community Data Sovereignty | Ensure the community retains legal and practical ownership, control, access, and possession (OCAP) of its language data and any model weights trained on it throughout the project lifecycle | Before collecting any language data from an Indigenous community, and when designing data governance agreements | [./community-data-sovereignty](./community-data-sovereignty.md) |
| Cyclical Engagement Process | Six-step iterative framework (seek community needs → engage representative bodies → negotiate control → create community benefit → store data accessibly → scale digital shells) for building language technologies with Indigenous communities; grounded in practitioner interviews | At the start of any project seeking community partnership; when designing engagement protocols or ethics applications | [./cyclical-engagement-process](./cyclical-engagement-process.md) |
| LISTED Framework for Culturally Aligned AI Deployment | Six-dimension audit framework (Language, Institution, Safety, Task, End-User Demography, Domain) with 12 design guidelines grounded in 8 real-world deployments across 7 countries and 18 languages; identifies human expert labor as the binding constraint | When scoping, designing, deploying, or diagnosing any AI system for a non-Western, multilingual, or high-stakes context | [./listed-framework-deployment-design](./listed-framework-deployment-design.md) |
| Human-in-the-Loop AI Safety Workflows | Structured process combining lightweight classifiers, LLM validation agents, and human expert review to ensure safe AI outputs in multilingual and high-stakes deployments where off-the-shelf safety models fail | When deploying AI in high-stakes domains or where off-the-shelf safety classifiers fail on code-mixed or low-resource language inputs | [./human-in-the-loop-ai-safety](./human-in-the-loop-ai-safety.md) |
| AI Extraction Protection Protocol | Technical and governance defenses to protect Indigenous digital language resources (dictionaries, corpora, conjugation tools) from unauthorized AI data mining; grounded in three documented extraction incidents from the Algonquian Dictionaries project | When maintaining any publicly accessible Indigenous language digital resource; when receiving external data access requests | [./ai-extraction-protection-protocol](./ai-extraction-protection-protocol.md) |
| Master Speaker Protocol | Collaboration practices that center the irreplaceable role of fluent Indigenous language Masters Speakers; structures researcher engagement to honor the oral transmission relationship, accommodate elder constraints (trauma, health, scheduling), and establish data rights before any recording begins | When any critically endangered language project involves working with elder fluent speakers | [./master-speaker-protocol](./master-speaker-protocol.md) |
| Endangered vs. Low-Resource Language Distinction | Three-category diagnostic framework (Elephant/Ocelot/Coyote) for correctly classifying the target language before selecting NLP methods and community engagement protocols; prevents applying Elephant-language methods to critically endangered Coyote languages | Before any language technology project — the first scoping step | [./endangered-vs-low-resource-distinction](./endangered-vs-low-resource-distinction.md) |
| Indigenous AI Development Cycle | Community-centered AI development cycle that places community usage, engagement, and sovereignty as structural pillars rather than ethical add-ons; contrasts with the traditional data-crawl pipeline; includes short-term (community usage → data collection → retraining) and long-term (data governance → model appropriation) sub-cycles with damage containment procedures | When starting any AI project involving an Indigenous community's language data | [./indigenous-ai-development-cycle](./indigenous-ai-development-cycle.md) |
| Thick Evaluation of Cultural Representation | Five-dimension participatory evaluation framework (incorrectness, missingness, specificity, coherence, connotation) for assessing AI cultural representation through community workshops; goes beyond accuracy benchmarks to capture socially situated and dynamic representation goals | When evaluating any AI system's cultural representation for a non-Western, Indigenous, or minority community | [./thick-evaluation-cultural-representation](./thick-evaluation-cultural-representation.md) |
| Machine-in-the-Loop Annotation | Human-AI collaboration paradigm where a partially-trained model pre-annotates or suggests candidates for human review, reducing annotation burden on small speaker communities by 3–5x; integrates uncertainty sampling and GWAP mechanics for learner participation | When building annotated corpora for endangered languages where expert annotator time is the binding constraint | [./machine-in-the-loop-annotation](./machine-in-the-loop-annotation.md) |
| Endangered Language NLP Roadmap | Three-stage sequencing framework (community principles → education-supporting tools → research-grade NLP) for organizing NLP work with critically endangered languages; requires Stage 1 community trust-building before any technical scoping; explicitly names and counters the "number games" anti-pattern | Before scoping any NLP project for a critically or severely endangered language | [./endangered-language-nlp-roadmap](./endangered-language-nlp-roadmap.md) |
