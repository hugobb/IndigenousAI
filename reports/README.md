# Reports

Research reports on specific technical or conceptual topics relevant to the IndigenousAI project. Each report is a focused deep-dive that synthesizes literature, working discussions, and technical reasoning on a single subject — going beyond what a literature review summary or the OVERVIEW synthesis can cover.

| File | Topic |
| --- | --- |

## When to write a report

Write a report when a question requires more focused treatment than a literature review entry or a `Draft.md` note:

- A specific technical question needs systematic analysis (e.g., tokenization strategies for polysynthetic languages)
- A design decision requires comparing multiple approaches in depth
- Background knowledge on a topic needs thorough documentation before a research or implementation decision

Reports are not tied to individual papers. They integrate across multiple sources, working discussions, and technical reasoning. They complement the literature review — which provides paper-level summaries and a cross-paper synthesis — by going deeper on a single focused question.

## Naming convention

Use lowercase kebab-case filenames that describe the topic:

- `tokenizer.md` — tokenization for morphologically rich languages
- `mohawk-morphology.md` — overview of Mohawk morphological structure
- `data-sovereignty-frameworks.md` — comparison of Indigenous data sovereignty frameworks
